# Changelog

## [0.0.0-fern-placeholder.6] - 2026-08-10
### Added
- **`xContentfulEnableAlphaFeature`** — new optional field on `BaseClientOptions` and `BaseRequestOptions` that sets the `x-contentful-enable-alpha-feature` request header (defaults to `"new-exo-entity-types"`), enabling per-client and per-request control of Contentful alpha features.

### Changed
- **Minimum Node.js version** lowered from `>=22.0.0` to `>=18.0.0`, broadening runtime compatibility.
